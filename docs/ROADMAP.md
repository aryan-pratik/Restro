# ROADMAP.md

## Phase 1 — Foundation
Next.js setup, TypeScript, Tailwind, shadcn, Prisma, PostgreSQL, Better Auth, Env vars, ESLint, Prettier.
Goal: Application boots successfully.

## Phase 2 — Database
Implement schema, migrations, seed script. Verify seeded data.

## Phase 3 — Authentication
Login, Logout, Session, Role handling, Protected routes.

## Phase 4 — Menu Management
Categories, Items, Add-ons, Search, Availability toggle, CRUD.

## Phase 5 — Table Management
Table grid, Table status, Open table, Close table, Table sessions.

## Phase 6 — POS
Table selection, Menu selection, Cart, Quantity, Modifiers, Notes, Order creation, Order update, Order total calculation.

## Phase 7 — KOT / Kitchen
Send KOT, Kitchen board, KOT status updates, Order status synchronization.

## Phase 8 — Billing
Bill generation, Discount, Tax, Service charge, Bill preview.

## Phase 9 — Payments
Cash, Card, UPI, Payment recording, Order paid, Table release.

## Phase 10 — Inventory
Inventory item, Stock adjustment, Purchases, Waste, Low-stock alerts, Transaction history.

## Phase 11 — Dashboard & Reports
Revenue, Orders, AOV, Payment breakdown, Top products, Daily sales.

## Phase 12 — Polish
Loading states, Error states, Toast notifications, Empty states, Confirm dialogs, Form validation, Permission checks, Pagination, Search, Filters, Audit logging.
